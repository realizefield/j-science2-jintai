ヒトの呼吸のしくみ（息を吸う・はく）

鼻や口から吸った空気は、気管を通り、枝分かれした気管支を通って肺に入ります。

肺には筋肉がないので、肺は自分でふくらんだり、ちぢんだりすることができません。肺のまわりのろっ骨（肋骨）とその間の筋肉、そして肺の下にある横隔膜が動くことで、空気が出入りします。

息を吸うとき息をはくとき
ろっ骨上がる下がる
横隔膜下がる上がる
胸の中の空間広くなるせまくなる
肺ふくらむ（空気が入る）ちぢむ（空気が出る）

ろっ骨と横隔膜は、いつも反対の向きに動きます。「吸うとき、ろっ骨は上、横隔膜は下」と覚えましょう。

【重要】
・肺には筋肉がない → ろっ骨と横隔膜の動きで空気を出し入れする
・息を吸う…ろっ骨が上がり、横隔膜が下がる → 肺がふくらむ
・息をはく…ろっ骨が下がり、横隔膜が上がる → 肺がちぢむ

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

肺には①がないため、自分でふくらむことができない。息を吸うときは、ろっ骨が②がり、③が下がって、肺が④。息をはくときは、ろっ骨が下がり、横隔膜が⑤がって、肺がちぢむ。

①  ②  ③  ④  ⑤ 
答え: ①=筋肉 / ②=上 / ③=横隔膜 / ④=ふくらむ / ⑤=上

Q2. 息を吸うとき、横隔膜はどのように動くか。

正解: イ：下がる　息を吸うときは横隔膜が下がり、胸の中の空間が広がって肺がふくらみます。

Q3. 肺が自分でふくらんだりちぢんだりできないのはなぜか。

正解: ア：肺には筋肉がないから　肺には筋肉がないので、ろっ骨と横隔膜の動きによって空気を出し入れしています。

Q4. 息をはくときの、ろっ骨と横隔膜の動きの組み合わせとして正しいものはどれか。

正解: ア：ろっ骨は下がり、横隔膜は上がる　息をはくときは、ろっ骨が下がり、横隔膜が上がって、胸の中がせまくなり肺がちぢみます。

Q5. 図の表の①〜⑥に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥ 
答え: ①=上がる / ②=下がる / ③=ふくらむ / ④=ちぢむ / ⑤=下がる / ⑥=上がる

肺の模型で呼吸のしくみを調べよう

ペットボトルとゴム風船、ゴム膜を使って、呼吸のしくみを調べる模型をつくることができます。模型の各部分は、ヒトの体の次の部分にあたります。

模型ヒトの体
ガラス管（ストロー）気管
ゴム風船肺
ペットボトルろっ骨で囲まれた胸の部分
ゴム膜横隔膜

ゴム膜（ひも）を引いたとき・もどしたとき

ゴム膜を下に引くと、ペットボトル内の空間が広がって圧力（気圧）が下がり、ゴム風船に空気が入ってふくらみます。これは息を吸うときのようすです。

ゴム膜をもどすと、ペットボトル内の圧力が上がり、ゴム風船から空気が出てしぼみます。これは息をはくときのようすです。

【重要】
・ゴム風船＝肺、ゴム膜＝横隔膜、ガラス管＝気管
・ゴム膜を引く → 圧力が下がる → 風船がふくらむ（息を吸う）
・ゴム膜をもどす → 圧力が上がる → 風船がしぼむ（息をはく）

Q1. 文中の①〜⑥に当てはまる語句を語群から選んで入れよう。

模型のゴム風船は①、ゴム膜は②、ガラス管は③にあたる。ゴム膜を下に引くと、ペットボトル内の圧力が④、ゴム風船は⑤。これは息を⑥ときのようすを表している。

①  ②  ③  ④  ⑤  ⑥ 
答え: ①=肺 / ②=横隔膜 / ③=気管 / ④=下がり / ⑤=ふくらむ / ⑥=吸う

Q2. 模型のゴム膜は、ヒトの体のどの部分にあたるか。

正解: エ：横隔膜　ゴム膜は、肺の下にある横隔膜にあたります。

Q3. 引いたゴム膜をもとにもどすと、ゴム風船はどうなるか。

正解: エ：しぼむ　ゴム膜をもどすとペットボトル内の圧力が上がり、ゴム風船から空気が出てしぼみます。息をはくときにあたります。

Q4. 図の①〜⑩に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧  ⑨  ⑩ 
答え: ①=上 / ②=下 / ③=ふくらむ / ④=ちぢむ / ⑤=下 / ⑥=上 / ⑦=肺 / ⑧=横隔膜 / ⑨=ふくらむ / ⑩=しぼむ

肺胞のつくりと気体の交換

気管は枝分かれして気管支となり、その先には肺胞という小さな袋がたくさんついています。肺胞のまわりは毛細血管が取り囲んでいます。

肺胞の中の空気から酸素が毛細血管の血液にとり入れられ（赤血球が運びます）、血液中の二酸化炭素が肺胞の中に出されます。これを気体の交換（ガス交換）といいます。

心臓から肺へ向かう血液が流れる血管を肺動脈（二酸化炭素が多い血液）、肺から心臓へもどる血液が流れる血管を肺静脈（酸素が多い血液）といいます。

肺胞がたくさんあることで、肺の内部の表面積が大きくなり、酸素と二酸化炭素の交換を効率よく行うことができます。

【重要】
・肺胞…気管支の先の小さな袋。まわりを毛細血管が取り囲む
・肺胞で、酸素を血液にとり入れ、二酸化炭素を出す
・肺動脈（心臓→肺）…二酸化炭素が多い／肺静脈（肺→心臓）…酸素が多い
・肺胞があることで表面積が大きくなり、効率よく気体を交換できる

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

気管支の先には①という小さな袋がたくさんあり、そのまわりを②が取り囲んでいる。肺胞では、空気中の③が血液にとり入れられ、血液中の④が肺胞に出される。肺胞がたくさんあることで、肺の⑤が大きくなり、効率よく気体の交換ができる。

①  ②  ③  ④  ⑤ 
答え: ①=肺胞 / ②=毛細血管 / ③=酸素 / ④=二酸化炭素 / ⑤=表面積

Q2. 肺胞がたくさんあることの利点として正しいものはどれか。

正解: ウ：表面積が大きくなり、効率よく気体の交換ができる　小さな肺胞がたくさんあることで、空気と血液がふれる表面積が大きくなります。小腸の柔毛と同じ考え方です。

Q3. 肺から心臓へもどる血液が流れる血管と、その血液の特ちょうの組み合わせとして正しいものはどれか。

正解: エ：肺静脈・酸素を多くふくむ　肺から心臓へもどる血管は肺静脈です。肺胞で酸素をとり入れたばかりなので、酸素を多くふくんでいます。

Q4. 肺胞でとり入れた酸素を全身へ運ぶ血液の成分はどれか。

正解: エ：赤血球　赤血球にふくまれるヘモグロビンが酸素と結びついて、全身へ運びます。

Q5. 図の①〜⑦に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦ 
答え: ①=肺胞 / ②=肺静 / ③=肺動 / ④=肺静 / ⑤=酸素 / ⑥=肺動 / ⑦=二酸化炭素
②④は肺から心臓へもどる「肺静脈」、③⑥は心臓から肺へ向かう「肺動脈」です。

血液の成分

血液は、固形の成分（赤血球・白血球・血小板）と、液体の成分（血しょう）からできています。

成分形はたらき
赤血球中央がくぼんだ円盤形ヘモグロビンという赤い色素をふくみ、酸素を運ぶ
白血球いろいろな形（形を変えて動く）体に入った細菌などの異物を分解して体を守る
血小板小さく、不規則な形出血したときに血液を固める（傷口をふさぐ）
血しょう液体養分や二酸化炭素などの不要な物質を運ぶ

ヘモグロビンの性質

ヘモグロビンは、酸素が多いところ（肺）では酸素と結びつき、酸素が少ないところ（体の各部の細胞）では酸素をはなす性質があります。この性質によって、肺でとり入れた酸素を全身の細胞に届けることができます。

【重要】
・赤血球…ヘモグロビンで酸素を運ぶ
・白血球…細菌などの異物を分解する
・血小板…出血したとき血液を固める
・血しょう…養分や不要な物質を運ぶ（液体成分）
・ヘモグロビン…酸素が多い所で結びつき、少ない所ではなす

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

血液の固形の成分のうち、酸素を運ぶのは①で、その中には②という赤い色素がふくまれている。細菌などの異物を分解するのは③、出血したときに血液を固めるのは④である。液体の成分である⑤は、養分や不要な物質を運ぶ。

①  ②  ③  ④  ⑤ 
答え: ①=赤血球 / ②=ヘモグロビン / ③=白血球 / ④=血小板 / ⑤=血しょう

Q2. ヘモグロビンの性質として正しいものはどれか。

正解: ア：酸素が多いところで酸素と結びつき、少ないところで酸素をはなす　肺（酸素が多い）で酸素と結びつき、体の細胞（酸素が少ない）で酸素をはなします。

Q3. 出血したときに血液を固めるはたらきをもつ成分はどれか。

正解: ウ：血小板　血小板は小さく不規則な形をしていて、出血したときに血液を固めて傷口をふさぎます。

Q4. 中央がくぼんだ円盤形をしている血液の成分はどれか。

正解: イ：赤血球　赤血球は中央がくぼんだ円盤形をしています。

Q5. 図の①〜④に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④ 
答え: ①=白血球 / ②=血しょう / ③=赤血球 / ④=血小板

血液と細胞の間の物質のやりとり（組織液）

毛細血管のかべはとてもうすく、血しょうの一部が毛細血管からしみ出して、細胞のまわりを満たしています。これを組織液といいます。

血液と細胞の間の物質のやりとりは、この組織液を仲立ちにして行われます。

・赤血球が運んできた酸素や、血しょうにとけた養分は、組織液を通して細胞にわたされます。
・細胞でできた二酸化炭素などの不要な物質は、組織液にとけて血液にもどされます。

組織液の一部はリンパ管に入り、リンパ液になります。

【重要】
・組織液…血しょうが毛細血管からしみ出て、細胞のまわりを満たしたもの
・酸素・養分 → 細胞へ ／ 二酸化炭素・不要な物質 → 血液へ
・リンパ管に入った組織液をリンパ液という

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

毛細血管からしみ出した①は、細胞のまわりを満たし、②とよばれる。②を通して、③や養分が細胞にわたされ、細胞からは④などの不要な物質が血液にもどされる。②の一部は⑤に入る。

①  ②  ③  ④  ⑤ 
答え: ①=血しょう / ②=組織液 / ③=酸素 / ④=二酸化炭素 / ⑤=リンパ管

Q2. 組織液とは何か。

正解: イ：血しょうが毛細血管からしみ出して、細胞のまわりを満たしたもの　組織液は、血しょうの一部が毛細血管のかべからしみ出したものです。

Q3. 細胞から組織液を通して血液にもどされる気体はどれか。

正解: ア：二酸化炭素　細胞の呼吸でできた二酸化炭素は、組織液にとけて血液にもどされ、肺からはき出されます。

Q4. 図の①〜④に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④ 
答え: ①=酸素 / ②=赤血球 / ③=二酸化炭素 / ④=組織液

ここまで学んだ「呼吸のしくみ」「肺の模型」「肺胞」について、入試問題で確認しましょう。

Q1. 図の模型で、ゴム膜を矢印の方向（下）に引いたときのようすとして正しいものはどれか。（和歌山県）

正解: エ：ペットボトル内の気圧が下がり、風船に空気が入る。息を吸うときにあたる。　ゴム膜（横隔膜）を下に引くと、ペットボトル内の空間が広がって気圧が下がり、風船（肺）に空気が入ります。

Q2. 図は、酸素を体内にとり入れるはたらきをする器官のつくりの一部である。この器官はどれか。

正解: エ：肺　図は、肺の気管支の先にある肺胞と、そのまわりの血管のようすです。

Q3. 同じ図で、血管Aを流れる血液をa、血管Bを流れる血液をbとしたとき、酸素と二酸化炭素の量の関係として正しいものはどれか。（秋田県）

正解: エ：酸素の量はbが多く、二酸化炭素の量はaが多い　血液は血管A→肺胞→血管Bと流れます。肺胞で酸素をとり入れ、二酸化炭素を出すので、Bの血液（b）は酸素が多く、Aの血液（a）は二酸化炭素が多くなります。

A：気管支の先に多数ある小さなふくろ　B：Aをとり囲む血管　C・D：Bの中の血液とAの中の空気の間でやりとりされる物質

A  B  C  D 
答え: A=肺胞 / B=毛細血管 / C=二酸化炭素 / D=酸素
Cは血液から肺胞へ出される二酸化炭素、Dは肺胞から血液へとり入れられる酸素です。

Q5. 図1・図2について、文中の①〜⑥に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥ 
答え: ①=横隔膜 / ②=ゴム膜 / ③=肺 / ④=気管 / ⑤=ふくらむ / ⑥=吸った
