目のつくりとはたらき

目・耳・鼻・舌・皮ふのように、外からの刺激を受けとる器官を感覚器官といいます。感覚器官には、刺激を受けとる感覚細胞があります。

目に入った光は、こうさい（虹彩）の中央にあるひとみを通り、レンズ（水晶体）で曲げられて、網膜に像を結びます。網膜には光の刺激を受けとる細胞があり、その刺激は視神経を通って脳へ送られます。

部分はたらき
こうさい（虹彩）ひとみの大きさを変えて、目に入る光の量を調節する。
明るいとき → ひとみは小さくなる／暗いとき → ひとみは大きくなる
レンズ（水晶体）厚さを変えてピントを合わせる。
近くを見るとき → 厚くなる／遠くを見るとき → うすくなる
網膜光の刺激を受けとる細胞がある。像は上下左右が逆にうつる
ガラス体目の中を満たす透明な部分。目の形を保つ
視神経網膜で受けとった刺激を脳へ伝える

網膜にうつる像は上下左右が逆ですが、脳でもとの向きとして感じとっています。カメラにたとえると、フィルム（センサー）は網膜、しぼりはこうさいにあたります。

【重要】
・光 → ひとみ → レンズ（水晶体）→ 網膜 → 視神経 → 脳
・こうさい…光の量を調節（明るい：ひとみ小／暗い：ひとみ大）
・レンズ…近くを見るとき厚く、遠くを見るときうすくなる
・網膜…光の刺激を受けとる細胞がある。像は上下左右が逆

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

光は①の中央のひとみから入り、②で曲げられて③に像を結ぶ。③で受けとった刺激は④を通って脳へ送られる。明るいところでは、ひとみは⑤なる。

①  ②  ③  ④  ⑤ 
答え: ①=こうさい / ②=レンズ / ③=網膜 / ④=視神経 / ⑤=小さく

Q2. こうさい（虹彩）のはたらきはどれか。

正解: エ：ひとみの大きさを変えて、目に入る光の量を調節する　こうさいは、ひとみの大きさを変えて光の量を調節します。

Q3. 近くのものを見るとき、レンズ（水晶体）はどうなるか。

正解: ア：厚くなる　近くを見るときはレンズが厚くなり、遠くを見るときはうすくなってピントを合わせます。

Q4. 網膜にうつる像の向きとして正しいものはどれか。

正解: ウ：上下左右が逆　網膜には上下左右が逆の像がうつりますが、脳でもとの向きとして感じとっています。

Q5. 図の①〜⑧に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧ 
答え: ①=光の量を調節する / ②=量 / ③=網膜 / ④=小さく / ⑤=大きく / ⑥=水晶体 / ⑦=厚く / ⑧=うすく
⑥はレンズの正式な名前「水晶体」です。

耳のつくりとはたらき

音は、空気の振動として耳に伝わります。

耳に入った音は、まず鼓膜をふるわせます。その振動は耳小骨で大きくされて、うずまき管に伝わります。うずまき管の中は液体で満たされていて、音の刺激を受けとる細胞があります。その刺激は聴神経を通って脳へ送られます。

部分はたらき
鼓膜音（空気の振動）を最初に受けとって振動する
耳小骨鼓膜の振動を大きくして、うずまき管に伝える
うずまき管中が液体で満たされ、音の刺激を受けとる細胞がある
聴神経うずまき管で受けとった刺激を脳へ伝える

耳は顔の左右に1つずつあるので、音の来る方向を知ることができます。

【重要】
・音 → 鼓膜 → 耳小骨 → うずまき管 → 聴神経 → 脳
・鼓膜…音の振動を最初に受ける
・耳小骨…振動を大きくして内耳（うずまき管）に伝える
・うずまき管…音の刺激を受けとる細胞がある

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

音は①の振動として耳に伝わり、まず②をふるわせる。その振動は③で大きくされ、④に伝わる。④で受けとった刺激は⑤を通って脳へ送られる。

①  ②  ③  ④  ⑤ 
答え: ①=空気 / ②=鼓膜 / ③=耳小骨 / ④=うずまき管 / ⑤=聴神経

Q2. 音の刺激を受けとる細胞があるのはどこか。

正解: ア：うずまき管　うずまき管の中は液体で満たされていて、音の刺激を受けとる細胞があります。

Q3. 耳小骨のはたらきとして正しいものはどれか。

正解: ウ：鼓膜の振動を大きくして、うずまき管に伝える　耳小骨は、鼓膜の振動を大きくしてうずまき管に伝えます。

Q4. 図の①〜③に当てはまる語句を語群から選んで入れよう。

①  ②  ③ 
答え: ①=鼓膜 / ②=うずまき管 / ③=耳小骨

Q5. 図のA〜Dに当てはまる語句を語群から選んで入れよう。

A  B  C  D 
答え: A=鼓膜 / B=耳小骨 / C=うずまき管 / D=聴神経

刺激の伝達と神経系

感覚器官で受けとった刺激は、信号となって神経を通り、脳やせきずいへ伝わります。そこで判断が行われ、命令の信号が筋肉へ送られて、体が動きます。

神経の種類ふくまれるもの・はたらき
中枢神経脳とせきずい。判断をしたり、命令を出したりする
末梢（まっしょう）神経中枢神経から枝分かれして全身に広がる神経。感覚神経と運動神経がある
感覚神経感覚器官で受けとった刺激の信号を、中枢神経へ伝える
運動神経中枢神経からの命令の信号を、筋肉へ伝える

中枢神経と末梢神経をまとめて神経系といいます。

意識して行う反応の信号の伝わり方

■ 手で物にふれて、その物を動かすとき（皮ふで受けとる刺激）
指（感覚器）→a 感覚神経→b せきずい→ c →d 大脳→ e →b せきずい→f 運動神経→筋肉

図のcは、せきずいから大脳へ信号が上っていく道すじ、eは大脳からせきずいへ命令が下りてくる道すじです。

■ 目で見て（耳で聞いて）反応するとき
目・耳→感覚神経→脳→せきずい→運動神経→筋肉

目・耳・鼻・舌のように脳に近い感覚器官からの信号は、せきずいを通らずに直接脳へ伝わります。

【重要】
・中枢神経…脳とせきずい（判断・命令）
・末梢神経…感覚神経（感覚器官→中枢）と運動神経（中枢→筋肉）
・皮ふの刺激：皮ふ→感覚神経→せきずい→脳→せきずい→運動神経→筋肉
・目・耳の刺激：目・耳→感覚神経→脳→せきずい→運動神経→筋肉

Q1. 文中の①〜④に当てはまる語句を語群から選んで入れよう。

神経系のうち、脳とせきずいを①神経、そこから枝分かれして全身に広がる神経を②神経という。②神経のうち、感覚器官からの信号を中枢へ伝えるのは③神経、中枢からの命令を筋肉へ伝えるのは④神経である。

①  ②  ③  ④ 
答え: ①=中枢 / ②=末梢 / ③=感覚 / ④=運動

Q2. 刺激の信号を受けとって判断し、どのように反応するかを命令するところはどこか。

正解: イ：脳　意識して行う反応では、脳が判断して命令を出します。

Q3. 手で物にふれて、その物を動かすとき、信号が伝わる順として正しいものはどれか。

正解: ウ：皮ふ→感覚神経→せきずい→脳→せきずい→運動神経→筋肉　皮ふからの信号は、せきずいを通って脳へ伝わり、脳からの命令はせきずいを通って筋肉へ伝わります。

Q4. 目で見た刺激の信号は、どのように伝わるか。

正解: ウ：せきずいを通らずに、直接脳へ伝わる　目・耳・鼻・舌など脳に近い感覚器官からの信号は、直接脳へ伝わります。

Q5. 図の①〜④に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④ 
答え: ①=大脳 / ②=せきずい / ③=末梢 / ④=中枢

Q6. 図の①〜⑧に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧ 
答え: ①=感覚 / ②=せきずい / ③=大脳 / ④=せきずい / ⑤=運動 / ⑥=大脳 / ⑦=感覚神経 / ⑧=運動神経
指からの信号は、a感覚神経→bせきずい→c→d大脳と伝わり、大脳からの命令がe→bせきずい→f運動神経→筋肉と伝わります。

4

反射

熱いやかんにうっかり手がふれたとき、「熱い」と感じる前に思わず手を引っこめます。このように、刺激に対して無意識に起こる反応を反射といいます。

■ 反射の信号の伝わり方（熱いものにふれて手を引っこめるとき）
皮ふ→感覚神経→せきずい→運動神経→筋肉

反射では、命令が脳ではなく、せきずいなどから直接出されます。信号が脳まで行かないので、刺激を受けてから反応するまでの時間が短くなります。「熱い」と感じるのは、信号が脳に届いたあと（手を引っこめたあと）です。

反射は、危険から体を守ったり、体のはたらきを調節したりするのに役立っています。

反射の例

・ひざの下を軽くたたくと、足がはね上がる
・目の前に急に物が飛んでくると、思わず目を閉じる
・熱いものにふれると、思わず手を引っこめる
・明るいところに出ると、ひとみが小さくなる
・運動をすると、脈拍数や心拍数が増える
・口の中に食べ物を入れると、だ液が出る

【重要】
・反射…刺激に対して無意識に起こる反応
・反射の経路：皮ふ→感覚神経→せきずい→運動神経→筋肉（脳を通らない）
・脳を通らないので、反応までの時間が短い
・危険から体を守るのに役立つ

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

刺激に対して無意識に起こる反応を①という。①では、命令が②から出されるので、信号が③を通らず、反応するまでの時間が④。①は、⑤から体を守るのに役立っている。

①  ②  ③  ④  ⑤ 
答え: ①=反射 / ②=せきずい / ③=脳 / ④=短い / ⑤=危険

Q2. 次のうち、反射の例はどれか。

正解: ア：目の前にボールが飛んできて、思わず目を閉じた　思わず目を閉じるのは、無意識に起こる反射です。ほかは、脳で判断してから行う反応です。

Q3. 熱いものにふれて手を引っこめたとき、信号が伝わる順として正しいものはどれか。

正解: イ：皮ふ→感覚神経→せきずい→運動神経→筋肉　反射では、せきずいから直接命令が出され、脳を通りません。

Q4. 熱いものにふれて手を引っこめたとき、「熱い」と感じるのはいつか。

正解: ア：手を引っこめたあと　手を引っこめる命令はせきずいから出されます。「熱い」と感じるのは、信号が脳に届いたあとです。

Q5. 図の①〜⑨に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧  ⑨ 
答え: ①=大脳 / ②=感覚 / ③=せきずい / ④=運動 / ⑤=反射 / ⑥=大脳 / ⑦=せきずい / ⑧=感覚 / ⑨=運動
反射では、指→a感覚神経→bせきずい→f運動神経→筋肉と伝わり、大脳を通りません。

骨と筋肉（運動のしくみ）

ヒトは、体を支えたり動かしたりする骨格と、筋肉のはたらきによって、姿勢を保ったり運動したりしています。

部分説明
関節骨と骨のつなぎ目。ここで体が曲がる
けん筋肉の両はしにあり、筋肉と骨をつなぐじょうぶな部分

筋肉は自分で縮むことはできますが、自分でのびることはできません。そのため、関節をまたいで2つの骨についた筋肉が対になってはたらきます。

内側の筋肉外側の筋肉
腕を曲げるとき縮むゆるむ
腕をのばすときゆるむ縮む
【重要】
・関節…骨と骨のつなぎ目／けん…筋肉と骨をつなぐ部分
・筋肉は縮むことしかできない → 2つの筋肉が対になってはたらく
・腕を曲げる：内側の筋肉が縮み、外側がゆるむ
・腕をのばす：外側の筋肉が縮み、内側がゆるむ

Q1. 文中の①〜④に当てはまる語句を語群から選んで入れよう。

骨と骨のつなぎ目を①、筋肉の両はしにあって筋肉と骨をつなぐ部分を②という。腕を曲げるとき、内側の筋肉は③、外側の筋肉は④。

①  ②  ③  ④ 
答え: ①=関節 / ②=けん / ③=縮む / ④=ゆるむ

Q2. 腕をのばすとき、筋肉はどのようになるか。

正解: イ：外側の筋肉が縮み、内側の筋肉がゆるむ　腕をのばすときは外側の筋肉が縮みます。曲げるときは内側の筋肉が縮みます。

Q3. 筋肉と骨をつないでいる部分を何というか。

正解: ウ：けん　筋肉の両はしにある、けんで骨とつながっています。

Q4. 筋肉が2つ対になって、関節をまたいで骨についているのはなぜか。

正解: ウ：筋肉は自分で縮むことはできるが、のびることはできないから　一方の筋肉が縮むと、もう一方の筋肉がのばされます。対になることで、曲げる・のばすの両方ができます。

草食動物と肉食動物（歯と目のつき方）

動物の歯や目のつき方は、食べ物や生活のしかたに合ったつくりになっています。

肉食動物（ライオンなど）草食動物（シマウマ・ウマなど）
歯犬歯が大きくするどい（えものをとらえ、肉を切りさく）草をかみ切る門歯と、すりつぶす臼歯が発達
目のつき方前向き。両目で見える範囲が広く、えものまでの距離をつかみやすい横向き。見える範囲（視野）が広く、敵を早く見つけやすい
【重要】
・肉食動物…犬歯が発達、目は前向き（距離がつかみやすい）
・草食動物…門歯と臼歯が発達、目は横向き（広い範囲が見える）

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

肉食動物は、えものをとらえて肉を切りさく①が発達し、草食動物は、草をかみ切る②と、すりつぶす③が発達している。また、肉食動物の目は④向きに、草食動物の目は⑤向きについている。

①  ②  ③  ④  ⑤ 
答え: ①=犬歯 / ②=門歯 / ③=臼歯 / ④=前 / ⑤=横

Q2. 草食動物の目が顔の横向きについていることの利点はどれか。

正解: ア：広い範囲を見わたせ、敵を早く見つけられる　目が横向きだと視野が広くなり、周りの敵に早く気づくことができます。

Q3. 肉食動物の目が顔の前向きについていることの利点はどれか。

正解: イ：両目で見える範囲が広く、えものまでの距離をつかみやすい　前向きの目は両目で見える範囲が広く、立体的に見えるので、距離をつかみやすくなります。

Q4. 草食動物で発達している歯の組み合わせはどれか。

正解: イ：門歯と臼歯　草食動物は、門歯で草をかみ切り、臼歯ですりつぶします。

「目のつくり」「耳のつくり」について、入試問題で確認しましょう。

正解: イ：網膜・光の刺激を受けとる細胞があり、像を結ぶ　Bは網膜で、光の刺激を受けとる細胞があり、像を結びます。

Q7. 物との距離をはかるのに適しているのはどちらの目で見たときか。また、ライオンとシマウマでは、物との距離をはかるのに適した目のつき方をしているのはどちらか。（愛媛県）

正解: ウ：両方の目・ライオン　目が顔の前向きについているライオン（肉食動物）は、両目で見える範囲が広く、えものまでの距離をはかるのに適しています。シマウマ（草食動物）は目が横についていて、広い範囲を見わたせます。

Q8. 文中の①・②に当てはまる語句を語群から選んで入れよう。

音が耳に届くと、図Aの①が振動する。この振動はBの耳小骨で増幅されて、Cの②に伝えられる。②の中にはリンパとよばれる液体が入っていて、音の刺激を受けとる感覚細胞が、この液体のゆれを音の刺激として受けとり、Dの聴神経（感覚神経）を通して信号を脳へ伝える。

①  ② 
答え: ①=鼓膜 / ②=うずまき管

入試問題にチャレンジ！刺激の伝達と反射

「刺激の伝達」「反射」について、入試問題で確認しましょう。

Q1. 図は、ヒトの神経系を模式的に表したものである。①〜②、A・Bに当てはまる語句を語群から選んで入れよう。

神経系は、①脳やせきずいをふくむ中心の部分と、②そこから枝分かれして体のすみずみへいきわたっている部分からできている。図のAの神経とBの神経は、それぞれ何というか。

①  ②  A  B 
答え: ①=中枢神経 / ②=末梢神経 / A=感覚神経 / B=運動神経

Q2. 図は、受けとった刺激の伝わり方を模式的に表したものである。a〜dに当てはまる語句を語群から選んで入れよう。

a：受けとった刺激の信号が伝わる神経　b：図のbの部分　c：刺激の信号を受けとり、どのように反応するかを命令する器官　d：cからの命令をc→b→dと送る神経

a  b  c  d 
答え: a=感覚神経 / b=せきずい / c=脳 / d=運動神経

Q3. 図のように、ものさしが落ちるのを見てつまむ実験を行った。Bが刺激を受けとった感覚器官と、ものさしをつまむ命令を出したところの組み合わせはどれか。

正解: エ：感覚器官：目　命令：脳　ものさしが落ちるのを目で見て、脳が判断して「つまめ」という命令を出しています。

Q4. Bは10cmの位置でものさしをつかんだ。ものさしが落ちるのを見てからつまむまでにかかった時間はどれか。

（ものさしが落ちる距離と時間：5cm…0.10秒、10cm…0.14秒、15cm…0.17秒、20cm…0.20秒、25cm…0.23秒、30cm…0.25秒）

正解: エ：0.14秒　表から、10cm落ちるのにかかる時間は0.14秒です。

Q5. 前の問題の反応時間のうち、脳での判断に0.11秒かかったとする。信号が神経を伝わった距離が1.7mのとき、信号が伝わる平均の速さはおよそ何m/sか。

正解: エ：約56.7m/s　神経を伝わるのにかかった時間は 0.14－0.11＝0.03秒。速さ＝1.7m÷0.03秒＝約56.7m/sです。

Q6. 図で、熱いものにうっかりさわって、熱いと感じる前に手を引っこめたとき、信号はどの順に伝わるか。（感覚器官）→（　）→（筋肉）

正解: ア：E→D→F　反射では、感覚神経Eからせきずい（D）を通って、すぐに運動神経Fへ命令が伝わります。

Q7. 同じ図で、「後ろから肩をたたかれたので振り返った」とき、信号はどの順に伝わるか。（感覚器官）→（　）→（筋肉）

正解: ウ：E→C→A→B→F　意識して行う反応なので、せきずい（C）を通って脳（A）へ伝わり、脳からの命令がせきずい（B）を通って運動神経Fへ伝わります。

Q8. 次の反応で、信号が伝わった順に語句を語群から選んで入れよう（同じ語句を何度使ってもよい）。（栃木県）

①プールの水に手を入れ、冷たさを確認したあと、水の中から手を出した。
②熱いやかんに手がふれたとき、熱いと感じる前に手を引っこめた。

①-1  ①-2  ①-3  ①-4  ①-5  ②-1  ②-2  ②-3 
答え: ①-1=皮ふ / ①-2=せきずい / ①-3=脳 / ①-4=せきずい / ①-5=筋肉 / ②-1=皮ふ / ②-2=せきずい / ②-3=筋肉
①は意識して行う反応なので脳を通ります。②は反射なので脳を通りません。

Q9. 次のア〜エのうち、反射の反応を2つ選んだ組み合わせはどれか。

ア　信号が青に変わったのを見て歩き始めた。
イ　暗いところから明るいところに出ると、ひとみが小さくなった。
ウ　目の前にボールが飛んできたので、思わず目を閉じた。
エ　投げられたボールの方向を見て走り出した。

正解: エ：イとウ　イとウは無意識に起こる反射です。アとエは、見たことを脳で判断してから行う反応です。
