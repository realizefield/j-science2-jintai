動脈と静脈

心臓から送り出される血液が流れる血管を動脈、心臓へもどってくる血液が流れる血管を静脈といいます。

血管つくり
動脈かべが厚く、弾力性がある（心臓から強い勢いで送り出される血液の圧力にたえるため）
静脈かべは動脈よりうすく、ところどころに血液の逆流を防ぐ弁がある

動脈血と静脈血

動脈血…酸素を多くふくんだ血液。あざやかな赤色をしています。
静脈血…二酸化炭素を多くふくんだ血液。暗い赤色をしています。

【注意】「動脈」には必ず「動脈血」が流れるとは限りません。肺動脈には静脈血、肺静脈には動脈血が流れます。
【重要】
・動脈…心臓から出る血液が流れる。かべが厚く弾力性がある
・静脈…心臓へもどる血液が流れる。逆流を防ぐ弁がある
・動脈血…酸素が多い／静脈血…二酸化炭素が多い
・肺動脈には静脈血、肺静脈には動脈血が流れる

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

心臓から送り出された血液が流れる血管を①、心臓にもどる血液が流れる血管を②という。②には、血液の③を防ぐ④がある。酸素を多くふくむ血液を⑤という。

①  ②  ③  ④  ⑤ 
答え: ①=動脈 / ②=静脈 / ③=逆流 / ④=弁 / ⑤=動脈血

Q2. かべが厚く、弾力性がある血管はどれか。

正解: ア：動脈　動脈は、心臓から送り出される血液の強い圧力にたえられるよう、かべが厚く弾力性があります。

Q3. 静脈にある弁のはたらきはどれか。

正解: ウ：血液の逆流を防ぐ　静脈は血液の勢いが弱いので、弁によって血液が逆向きに流れるのを防いでいます。

Q4. 二酸化炭素を多くふくみ、暗い赤色をした血液を何というか。

正解: エ：静脈血　二酸化炭素を多くふくむ血液を静脈血といいます。

Q5. 図の①〜④に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④ 
答え: ①=動 / ②=静 / ③=動脈 / ④=静脈

心臓のつくり

心臓は筋肉でできていて、規則正しく縮んだりゆるんだり（拍動）することで、血液を全身に送り出すポンプのはたらきをしています。

ヒトの心臓には、右心房・右心室・左心房・左心室の4つの部屋があります。

・心房…血液がもどってくる部屋
・心室…血液を送り出す部屋

【図の見方】「右・左」は、図を見ている人ではなく、心臓をもつ人の体の右・左で決めます。そのため、正面から見た図では右心房・右心室が向かって左側にかかれます。
部屋つながる血管血液の流れ
右心房大静脈全身からもどった血液が入る
右心室肺動脈肺へ血液を送り出す
左心房肺静脈肺からもどった血液が入る
左心室大動脈全身へ血液を送り出す（かべがいちばん厚い）

心房と心室の間などには弁があり、血液が逆流しないようになっています。

【重要】
・心臓の4つの部屋…右心房・右心室・左心房・左心室
・左心室のかべがもっとも厚い（全身に血液を送り出すため）
・肺動脈…二酸化炭素を最も多くふくむ血液が流れる
・肺静脈…酸素を最も多くふくむ血液が流れる

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

心臓の4つの部屋のうち、全身からもどった血液が入るのは①、肺へ血液を送り出すのは②、肺からもどった血液が入るのは③、全身へ血液を送り出すのは④である。かべがもっとも厚いのは⑤である。

①  ②  ③  ④  ⑤ 
答え: ①=右心房 / ②=右心室 / ③=左心房 / ④=左心室 / ⑤=左心室

Q2. 左心室から全身へ血液を送り出す血管はどれか。

正解: ウ：大動脈　左心室から出た血液は、大動脈を通って全身へ送られます。

Q3. 酸素を最も多くふくむ血液が流れている血管はどれか。

正解: ウ：肺静脈　肺で酸素をとり入れたばかりの血液が流れる肺静脈が、最も酸素を多くふくんでいます。

Q4. 正面から見た心臓の図で、右心房・右心室が向かって左側にかかれているのはなぜか。

正解: イ：心臓をもつ人の体の右・左で呼ぶため、正面から見ると左右が逆になるから　向かい合って見ているので、その人の「右」は見ている人から見て「左」になります。

Q5. 図の①〜⑩に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧  ⑨  ⑩ 
答え: ①=肺動 / ②=大動 / ③=大静 / ④=肺静 / ⑤=右心房 / ⑥=右心室 / ⑦=左心房 / ⑧=左心室 / ⑨=二酸化炭素 / ⑩=酸素

3

肺循環と体循環

血液は、心臓から出て全身をめぐり、また心臓にもどってきます。血液の通り道は、次の2つに分けられます。

循環血液の流れはたらき
肺循環右心室→肺動脈→肺→肺静脈→左心房肺で二酸化炭素を出し、酸素をとり入れる
体循環左心室→大動脈→体の各部→大静脈→右心房細胞に酸素と養分をわたし、二酸化炭素や不要な物質を受けとる

血管の名前の覚え方

・心臓から出ていく血管 → 「動脈」／心臓にもどる血管 → 「静脈」
・肺とつながる血管 → 「肺○脈」／体とつながる血管 → 「大○脈」

【重要】
・肺循環…右心室→肺動脈→肺→肺静脈→左心房
・体循環…左心室→大動脈→体の各部→大静脈→右心房
・酸素が最も多い血液…肺静脈／二酸化炭素が最も多い血液…肺動脈

Q1. 文中の①〜⑥に当てはまる語句を語群から選んで入れよう。

肺循環は、右心室→①→肺→②→左心房の順に血液が流れる。体循環は、左心室→③→体の各部→④→右心房の順に流れる。肺循環では、血液は肺で⑤をとり入れ、⑥を出す。

①  ②  ③  ④  ⑤  ⑥ 
答え: ①=肺動脈 / ②=肺静脈 / ③=大動脈 / ④=大静脈 / ⑤=酸素 / ⑥=二酸化炭素

Q2. 肺循環の血液の流れとして正しいものはどれか。

正解: イ：右心室→肺動脈→肺→肺静脈→左心房　肺循環は右心室から始まり、肺動脈→肺→肺静脈を通って左心房にもどります。

Q3. 体循環のはじまりとなる心臓の部屋はどれか。

正解: イ：左心室　体循環は、左心室から大動脈へ血液が送り出されるところから始まります。

Q4. 二酸化炭素を最も多くふくむ血液が流れている血管はどれか。

正解: イ：肺動脈　全身から集まった血液が肺へ向かう肺動脈に、二酸化炭素が最も多くふくまれています。

Q5. 静脈なのに、動脈血（酸素を多くふくむ血液）が流れている血管はどれか。

正解: ア：肺静脈　肺静脈は心臓にもどる血管なので「静脈」ですが、肺で酸素をとり入れた動脈血が流れています。

4

血液循環のモデル図

血液循環のようすを模式的に表した図をモデル図といいます。入試によく出るので、次の血管を必ず覚えましょう。

血液の特ちょう血管理由
酸素が最も多い肺静脈肺で酸素をとり入れた直後
二酸化炭素が最も多い肺動脈全身から二酸化炭素を集めて肺へ向かう
養分が最も多い（食後）肝門脈小腸で吸収した養分を肝臓へ運ぶ
尿素などの不要物が最も少ないじん静脈じん臓で不要物がこしとられた直後
【重要】
・酸素最多…肺静脈／二酸化炭素最多…肺動脈
・養分最多（食後）…肝門脈（小腸→肝臓）
・尿素などの不要物最少…じん静脈（じん臓から出る血管）

Q1. 図の①〜⑩に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧  ⑨  ⑩ 
答え: ①=肺動脈 / ②=肺静脈 / ③=大静脈 / ④=大動脈 / ⑤=右心房 / ⑥=右心室 / ⑦=左心房 / ⑧=左心室 / ⑨=肺静 / ⑩=肺動

Q2. 文中の①〜④に当てはまる語句を語群から選んで入れよう。

酸素を最も多くふくむ血液が流れるのは①、二酸化炭素を最も多くふくむ血液が流れるのは②である。食後、ブドウ糖やアミノ酸などの養分を最も多くふくむ血液が流れるのは、小腸から肝臓へ向かう③である。尿素などの不要物が最も少ない血液が流れるのは、じん臓から出る④である。

①  ②  ③  ④ 
答え: ①=肺静脈 / ②=肺動脈 / ③=肝門脈 / ④=じん静脈

Q3. 肝門脈は、どこからどこへ血液を運ぶ血管か。

正解: ア：小腸から肝臓へ　肝門脈は、小腸で吸収したブドウ糖やアミノ酸を肝臓へ運ぶ血管です。

Q4. 尿素などの不要物が最も少ない血液が流れている血管はどれか。

正解: イ：じん静脈　じん臓で不要物がこしとられた直後の血液が流れるじん静脈が、不要物の最も少ない血管です。

5

不要な物質の排出（肝臓とじん臓）

図のように、背中側の腰の上あたりに左右1対のじん臓があります。じん臓でつくられた尿は輸尿管を通ってぼうこうにためられ、体外に出されます。

細胞では、養分を分解してエネルギーをとり出しています（細胞による呼吸）。このとき、不要な物質ができます。

分解されるものできる不要な物質体の外へ出す方法
炭水化物・脂肪など二酸化炭素と水二酸化炭素は肺からはき出す
タンパク質二酸化炭素と水、有害なアンモニア肝臓で害の少ない尿素に変える → じん臓でこしとり尿として出す

じん臓のはたらき

じん臓は、血液中の尿素などの不要な物質や、余分な水分・塩分をこしとって尿をつくります。また、血液中の水分や塩分の量を調節しています。

尿は輸尿管を通ってぼうこうに一時ためられ、体外に出されます。不要な物質の一部は、汗として皮ふからも出されます。

【重要】
・アンモニア（有害）→ 肝臓で尿素（害が少ない）に変える
・じん臓…血液中の尿素などをこしとって尿をつくる。水分や塩分の量も調節
・じん臓 → 輸尿管 → ぼうこう（尿を一時ためる）→ 体外へ
・二酸化炭素は肺から、尿素は尿や汗として排出される

Q1. 文中の①〜⑥に当てはまる語句を語群から選んで入れよう。

タンパク質が分解されると、有害な①ができる。①は②で害の少ない③に変えられる。③はじん臓で血液からこしとられて④となり、⑤を通って⑥に一時ためられてから体外に出される。

①  ②  ③  ④  ⑤  ⑥ 
答え: ①=アンモニア / ②=肝臓 / ③=尿素 / ④=尿 / ⑤=輸尿管 / ⑥=ぼうこう

Q2. アンモニアを害の少ない尿素に変える器官はどれか。

正解: イ：肝臓　有害なアンモニアは、肝臓で害の少ない尿素に変えられます。

Q3. じん臓のはたらきの組み合わせとして正しいものはどれか。

正解: イ：尿素などの不要物をこしとる・水分や塩分の量を調節する　じん臓は、血液中の尿素などの不要物や余分な水分・塩分をこしとって尿をつくり、水分や塩分の量を調節します。

Q4. 尿を一時的にためておく器官はどれか。

正解: イ：ぼうこう　じん臓でつくられた尿は、輸尿管を通ってぼうこうにためられます。

Q5. 図の①〜⑯に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧  ⑨  ⑩  ⑪  ⑫  ⑬  ⑭  ⑮  ⑯ 
答え: ①=じん臓 / ②=輸尿管 / ③=ぼうこう / ④=水 / ⑤=二酸化炭素 / ⑥=水 / ⑦=二酸化炭素 / ⑧=アンモニア / ⑨=肝臓 / ⑩=尿素 / ⑪=尿 / ⑫=水分 / ⑬=塩分 / ⑭=尿素 / ⑮=輸尿管 / ⑯=ぼうこう
④と⑤、⑥と⑦、⑫〜⑭は順番が入れかわっていても正解です。

入試問題にチャレンジ！心臓と血管

「動脈と静脈」「心臓のつくり」「肺循環と体循環」について、入試問題で確認しましょう。

Q1. 図のa〜dの血管の名前を語群から選んで入れよう。

a  b  c  d 
答え: a=大静脈 / b=大動脈 / c=肺動脈 / d=肺静脈

Q2. 図は心臓と血管のつながりを表している。血液の流れる順にa〜d、A〜Dを並べたものとして正しいものはどれか。ただし、cから始めること。

正解: ウ：c→A→C→a→b→B→D→d　c（大静脈）→A（右心房）→C（右心室）→a（肺動脈）→肺→b（肺静脈）→B（左心房）→D（左心室）→d（大動脈）の順です。

Q3. 同じ図で、心臓とつながっていて動脈血が流れている2つの血管の組み合わせはどれか。

正解: イ：b（肺静脈）とd（大動脈）　肺で酸素をとり入れた後の血液が流れるb（肺静脈）とd（大動脈）に、動脈血が流れています。

Q4. 同じ図のA〜Dのうち、静脈血が流れている部屋の組み合わせはどれか。

正解: エ：AとC　全身からもどった静脈血は、A（右心房）→C（右心室）を通って肺へ送られます。

Q5. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

心臓から出た血液が流れる血管を①といい、体の各部から心臓にもどる血液が流れる血管を②という。これらの血管のうち、図のXの③があるのは④である。③は血液の⑤を防ぐ役割をはたしている。

①  ②  ③  ④  ⑤ 
答え: ①=動脈 / ②=静脈 / ③=弁 / ④=静脈 / ⑤=逆流

Q6. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

ヒトの血液循環のうち、右心室→（ア）→肺→（イ）→左心房と流れる道すじを①という。この道すじを流れる間に血液は、肺で②をとり入れて③を排出する。血液が、左心室→（エ）→からだの各部分→（ウ）→右心房と流れる道すじを④という。この間に血液は、細胞に⑤と養分をあたえ、細胞から③などの不要な物質を受けとる。

①  ②  ③  ④  ⑤ 
答え: ①=肺循環 / ②=酸素 / ③=二酸化炭素 / ④=体循環 / ⑤=酸素

入試問題にチャレンジ！血液の循環と排出

「血液循環のモデル図」「排出」について、入試問題で確認しましょう。

Q1. 図は、じん臓とそのまわりのつくりを表している。A〜C、X・Yに当てはまる語句を語群から選んで入れよう。

A〜Cは器官の名前、X・Yは血液の流れから考えて「動脈」か「静脈」かを答えよう。

A  B  C  X  Y 
答え: A=じん臓 / B=輸尿管 / C=ぼうこう / X=動脈 / Y=静脈

Q2. 同じ図の血管X・Yのうち、不要物が少ない血液が流れているのはどちらか。

正解: イ：Y　Yはじん臓から出る血管（じん静脈）です。じん臓で不要物がこしとられた後なので、不要物が少なくなっています。

Q3. 図は、ヒトの血液の循環を模式的に表したものである。尿素が最も少ない血液が流れている血管はどれか。

正解: エ：d　dはじん臓から出る血管です。じん臓で尿素がこしとられた直後なので、尿素が最も少なくなっています。

Q4. 同じ図で、食後、ブドウ糖やアミノ酸が最も多い血液が流れている血管はどれか。

正解: ウ：c　cは小腸から肝臓へ向かう肝門脈です。小腸で吸収した養分を運びます。

Q5. 同じ図で、酸素が最も多い血液と、二酸化炭素が最も多い血液が流れている血管の組み合わせはどれか。

正解: ア：酸素：b　二酸化炭素：a　b（肺から心臓へもどる肺静脈）は酸素が最も多く、a（心臓から肺へ向かう肺動脈）は二酸化炭素が最も多くなっています。

Q6. 図は血液の流れと各器官のつながりを示した模式図である。①〜⑦にあてはまる血管を、図のア〜クから選んで入れよう（同じ記号を何回使ってもよい）。

Q7. 文中の①〜⑥に当てはまる語句を語群から選んで入れよう。
