消化・消化管・消化酵素とは？

食べたものを、体に吸収しやすい小さな物質に変えるはたらきを消化といいます。

消化を行う口・食道・胃・小腸・大腸などを消化器官、これらがひとつながりになった管を消化管といいます。

消化管に出される液を消化液、その中で栄養分を分解する物質を消化酵素といいます。だ液のアミラーゼや胃液のペプシンが代表的な消化酵素です。

【重要】
・消化…食物を体に吸収しやすい小さな物質に変えるはたらき
・消化管…口→食道→胃→小腸→大腸→肛門とつながる1本の管
・消化酵素…だ液のアミラーゼ、胃液のペプシンなど
・胆汁には消化酵素がふくまれていません（脂肪を細かくするだけ）

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

食物を体に吸収しやすい小さな物質に変えるはたらきを①という。①を行う器官を②といい、これらがひとつながりになった管を③という。①を行うために分泌される液を④、④の中で栄養分を分解するはたらきをもつ物質を⑤という。

①  ②  ③  ④  ⑤ 
答え: ①=消化 / ②=消化器官 / ③=消化管 / ④=消化液 / ⑤=消化酵素

Q2. 消化液の中で、消化酵素をふくまないものはどれか。

正解: ウ：胆汁　胆汁には消化酵素がふくまれず、脂肪を細かい粒にして消化酵素が働きやすくする役割をもっています。

Q3. 消化酵素のはたらきとして正しいのはどれか。

正解: イ：特定の物質を分解する　消化酵素は決まった物質にだけ働き、自分自身は変化しません。

Q4. アミラーゼがふくまれる消化液はどれか。

正解: イ：だ液　だ液にふくまれるアミラーゼは、デンプンを糖に分解します。

Q5. ペプシンがふくまれる消化液はどれか。

正解: イ：胃液　胃液にふくまれるペプシンは、タンパク質を分解します。

Q6. 消化器官の図の①〜⑫に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧  ⑨  ⑩  ⑪  ⑫ 
答え: ①=口 / ②=だ液せん / ③=食道 / ④=胃 / ⑤=すい臓 / ⑥=大腸 / ⑦=水分 / ⑧=小腸 / ⑨=直腸 / ⑩=胆汁 / ⑪=胆のう / ⑫=肝臓

だ液のはたらきを調べよう（実験）

だ液にはアミラーゼという消化酵素があり、デンプンを糖に分解します。

だ液は体温に近い37～40℃でよく働き、70℃以上になるとはたらきを失います。

デンプンと糖を見分ける方法

薬品使い方結果
ヨウ素液加えるだけデンプンがあると青紫色
ベネジクト液加えて加熱糖があると赤褐色の沈殿

加熱するときは、突沸を防ぐため沸とう石を入れます。

デンプン溶液だけのA、デンプン溶液とだ液のBを40℃で温めると、Bだけデンプンが糖に変わります。

【重要】
・アミラーゼ…だ液の消化酵素。デンプンを糖に分解する
・だ液がよく働く温度…37～40℃
・デンプンの検出…ヨウ素液（青紫色）
・糖の検出…ベネジクト液＋加熱（赤褐色の沈殿）
・加熱時は沸とう石で突沸を防ぐ

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

だ液にふくまれる消化酵素①は、デンプンを②に分解する。デンプンの検出には③を使い、青紫色に変化する。糖の検出には④を使い、加熱すると赤褐色の沈殿ができる。加熱時は突沸を防ぐため⑤を入れる。

①  ②  ③  ④  ⑤ 
答え: ①=アミラーゼ / ②=糖 / ③=ヨウ素液 / ④=ベネジクト液 / ⑤=沸とう石

Q2. だ液がもっともよく働く温度はどれか。

正解: ウ：37～40℃　だ液は体温に近い温度でもっともよく働きます。

Q3. デンプンがあると青紫色に変化する薬品はどれか。

正解: イ：ヨウ素液　デンプンの検出にはヨウ素液を使います。

Q4. 糖があると加熱後に赤褐色の沈殿ができる薬品はどれか。

正解: イ：ベネジクト液　糖の検出にはベネジクト液を加えて加熱します。

Q5. 実験で、だ液を加えたのは試験管A・Bのどちらか。

正解: イ：試験管B　試験管Bにはデンプン溶液とだ液を入れました。

セロハンを使った実験（発展）

セロハンの膜には小さな穴があり、小さな粒だけを通し、大きな粒は通しません。

【実験】
Aには、デンプン溶液のみをセロハンの袋に入れ、水に浸します。
Bには、デンプン溶液にだ液を加えたものをセロハンの袋に入れ、水に浸します。

問）Aのセロハンの袋の内側と外側、Bのセロハンの袋の内側と外側の部分で、それぞれヨウ素反応・ベネジクト反応が起こるかどうか答えなさい。

この実験では、セロハンの袋の内側の液と、袋の外に出た外側の水の両方を調べます。

ヨウ素反応ベネジクト反応
Aの内側○ 青紫色になる✕ 変化なし
Aの外側✕ 変化なし✕ 変化なし
Bの内側✕ 変化なし○ 赤褐色の沈殿
Bの外側✕ 変化なし○ 赤褐色の沈殿

Aにはだ液を加えていないので、袋の中はデンプンのままです。デンプンの粒は大きいためセロハンの外に出られず、内側だけヨウ素反応が起こり、外側はヨウ素反応・ベネジクト反応ともに変化しません。

Bはだ液のはたらきでデンプンがほぼすべて糖に変わっているため、内側でもヨウ素反応は起こりません。糖の粒は小さいためセロハンを通り抜けられるので、内側だけでなく外側の水にもベネジクト反応が現れます。

【重要】
・セロハンの穴…小さな粒だけを通す
・デンプン（大きい）→通れない／糖（小さい）→通れる
・消化…大きな粒を小さな粒に変えて、吸収できるようにするはたらき

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

セロハンの穴は①な粒だけを通し、②な粒は通さない。Aの袋（③のまま）を入れた水は変化しなかったが、Bの袋（分解された④）を入れた水はベネジクト液で⑤の沈殿ができた。

①  ②  ③  ④  ⑤ 
答え: ①=小さ / ②=大き / ③=デンプン / ④=糖 / ⑤=赤褐色

Q2. セロハンの穴を通れるのはどちらの粒か。

正解: イ：小さい粒　セロハンの穴は小さな粒だけを通します。

Q3. Aの袋を入れたビーカーの水にベネジクト液を加えて加熱した結果はどれか。

正解: ウ：変化なし　Aの中身はデンプンのままで、セロハンを通れず水の中に出てこないため変化しません。

Q4. Bの袋を入れたビーカーの水にベネジクト液を加えて加熱した結果はどれか。

正解: イ：赤褐色の沈殿ができる　Bの中身は糖に分解され、セロハンを通り抜けて水の中に出てきたためです。

Q5. この実験からわかることとして、もっとも正しいものはどれか。

正解: イ：消化された物質の粒は、もとの物質より小さくなる　デンプン（大きい粒）が消化されて糖（小さい粒）になり、セロハンを通れるようになりました。

Q6. Aには、デンプン溶液のみをセロハンの袋に入れ、水に浸します。Bには、デンプン溶液にだ液を加えたものをセロハンの袋に入れ、水に浸します。Aのセロハンの袋の内側と外側、Bのセロハンの袋の内側と外側の部分で、それぞれヨウ素反応・ベネジクト反応が起こるかどうかを正しく表しているものはどれか。

正解: ア　デンプンの粒は大きいため、セロハンの穴を通り抜けることができません。そのため、Aの内側にはデンプンが残っているのでヨウ素反応（青紫色）が起こりますが、外側の水にはデンプンが出てこないため、内側・外側とも反応は起こりません。

一方、Bはだ液のアミラーゼによってデンプンが糖（麦芽糖など）に分解されています。糖の粒はデンプンより小さいため、セロハンの穴を通り抜けることができます。そのため、Bは内側だけでなく外側の水にも糖が出てきて、内側・外側の両方でベネジクト反応（赤褐色の沈殿）が起こります。

この実験から、消化された物質（糖）の粒は、もとの物質（デンプン）の粒より小さくなることがわかります。

Q7. 今度はA・Bの中身を入れ替えます。Aには、デンプン溶液にだ液を加えたものをセロハンの袋に入れ、水に浸します。Bには、デンプン溶液のみをセロハンの袋に入れ、水に浸します。Aのセロハンの袋の内側と外側、Bのセロハンの袋の内側と外側の部分で、それぞれヨウ素反応・ベネジクト反応が起こるかどうかを正しく表しているものはどれか。

正解: ア　今度はAにだ液が入っています。Aの中のデンプンはすでに糖に分解されているので、糖の粒はセロハンの穴を通り抜けられます。そのため、Aは内側だけでなく外側の水にもベネジクト反応（赤褐色の沈殿）が起こります。

一方Bはデンプン溶液のみなので、デンプンの粒が大きくセロハンを通れず、内側だけヨウ素反応（青紫色）が起こります。

A・Bどちらに何が入っているかをよく確認しないと、前の問題と同じ答え（イ）を選んでしまうミスが起こりやすいので注意しましょう。大切なのは記号ではなく、だ液が入っているかどうかです。

小腸のつくりと養分の吸収

デンプン・タンパク質・脂肪は消化液によって分解され、小腸で吸収されます。

小腸の内側には図のような柔毛という小さな突起が多数あり、吸収の表面積を大きくしています。

デンプンはブドウ糖、タンパク質はアミノ酸、脂肪は脂肪酸とモノグリセリドに分解されます。ブドウ糖とアミノ酸は柔毛の中の毛細血管に、脂肪酸とモノグリセリドはリンパ管に吸収されます。

消化液のはたらき

【重要】
・柔毛…小腸の突起。吸収の表面積を大きくする
・デンプン→ブドウ糖／タンパク質→アミノ酸／脂肪→脂肪酸＋モノグリセリド
・ブドウ糖・アミノ酸→毛細血管／脂肪酸・モノグリセリド→リンパ管
・すい液はデンプン・タンパク質・脂肪の3つすべてに働く
・胆汁には消化酵素がない（脂肪を細かくするだけ）
・覚え方「1,2,3・1,2,3・1,2」

Q1. 文中の①〜⑤に当てはまる語句を語群から選んで入れよう。

小腸の内側には①という突起があり、吸収の②を大きくしている。デンプンは③に、タンパク質は④に、脂肪は⑤とモノグリセリドに分解されて吸収される。

①  ②  ③  ④  ⑤ 
答え: ①=柔毛 / ②=表面積 / ③=ブドウ糖 / ④=アミノ酸 / ⑤=脂肪酸

Q2. 柔毛の役割はどれか。

正解: イ：吸収の表面積を大きくする　柔毛が無数にあることで、効率よく養分を吸収できます。

Q3. デンプンは最終的に何になるか。

正解: ウ：ブドウ糖　デンプンは最終的にブドウ糖に分解されます。

Q4. デンプン・タンパク質・脂肪の3つすべてに働く消化液はどれか。

正解: ウ：すい液　すい液はデンプン・タンパク質・脂肪のすべてを分解できます。

Q5. 脂肪は最終的に何に分解されるか。

正解: イ：脂肪酸とモノグリセリド　脂肪は脂肪酸とモノグリセリド（グリセリン）に分解されます。

Q6. 小腸のつくりの図の①〜⑤に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤ 
答え: ①=柔毛 / ②=毛細血管 / ③=リンパ管 / ④=柔毛 / ⑤=表面積

Q7. 消化液のはたらきの図の①〜⑩に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧  ⑨  ⑩ 
答え: ①=デンプン / ②=たんぱく質 / ③=脂肪 / ④=アミラーゼ / ⑤=ペプシン / ⑥=ブドウ糖 / ⑦=アミノ酸 / ⑧=脂肪酸 / ⑨=モノグリセリド / ⑩=消化酵素

入試問題にチャレンジ！セロハンを使った実験

右の図のように、試験管A、Bを体温くらいの湯に10分間入れてあたためた。試験管A・Bの液をそれぞれ試験管a～dに分け、a、bにヨウ素液を、c、dにベネジクト液を加えて実験した（A→a・c、B→b・d）。これについて、次の問いに答えなさい。

なお、試験管Aにはデンプンのりと水を、試験管Bにはデンプンのりとだ液を入れてある。

(1) 試験管Aのように、1つの条件以外をすべて同じにして行う実験を何というか。

正解: イ：対照実験　だ液の効果だけを確かめるために、だ液の有無以外の条件をすべて同じにしています。

(2) 試験管a（Aの液＋ヨウ素液）の反応はどれか。

正解: ア：青紫色になる　Aにはだ液を入れていないため、デンプンのまま残っています。

(3) 試験管b（Bの液＋ヨウ素液）の反応はどれか。

正解: ウ：変化しない　Bはだ液の働きでデンプンが分解され、デンプンが残っていないためです。

(4) 試験管c（Aの液＋ベネジクト液）の反応はどれか。

正解: ウ：変化しない　Aには糖ができていないため、ベネジクト液を加えても変化しません。

(5) 試験管d（Bの液＋ベネジクト液）の反応はどれか。

正解: イ：赤褐色の沈殿ができる　Bはだ液の働きで糖ができているためです。

(6) 試験管bとdの結果より、デンプンがだ液によって何に変わったことがわかるか。

正解: イ：麦芽糖などの糖　だ液のアミラーゼによってデンプンが糖に分解されました。

さらに、試験管A・Bの液をそれぞれセロハンのふくろに入れ、ビーカーの水につけたまましばらく放置してから、ビーカー側の水を調べた。

(7) ビーカー側の水にヨウ素液を加えると、A・Bのふくろを入れたほうはそれぞれどうなるか。

正解: ウ：A・Bどちらも変化しない　デンプンの粒は大きくてセロハンを通れないため、ビーカーの水にはデンプンが出てきません。

(8) ビーカー側の水にベネジクト液を加えて加熱すると、A・Bのふくろを入れたほうはそれぞれどうなるか。

正解: イ：Bだけ赤褐色の沈殿ができる　Bでできた糖の粒は小さいのでセロハンを通り抜け、ビーカーの水の中に出てきます。この結果から、消化された物質の粒はもとの物質より小さくなることがわかります。

右の図のように、4本の試験管A～Dにうすいデンプン溶液を同量ずつ入れ、A・Cにはだ液を、B・Dには水を加えて、A～Dを約40℃の湯に10分間入れた。

7

発展：吸収された養分のゆくえ（肝門脈・リンパ管）

毛細血管に吸収されたブドウ糖とアミノ酸は、「肝門脈」という血管を通って肝臓にたくわえられます。

リンパ管に吸収された脂肪酸とモノグリセリドは、「胸管」という管を通って大静脈に入り、心臓から全身に配られます。

門脈とは、内臓から出た血液が心臓に戻る前に別の器官を通る血管のことです。

【重要】
・ブドウ糖・アミノ酸…毛細血管→肝門脈→肝臓
・脂肪酸・モノグリセリド…リンパ管→胸管→大静脈→心臓→全身
・肝門脈…消化管からの血液が心臓に戻る前に肝臓を通る血管

Q1. 図の①〜⑮に当てはまる語句を語群から選んで入れよう。

①  ②  ③  ④  ⑤  ⑥  ⑦  ⑧  ⑨  ⑩  ⑪  ⑫  ⑬  ⑭  ⑮ 
答え: ①=ブドウ糖 / ②=アミノ酸 / ③=脂肪酸 / ④=モノグリセリド / ⑤=毛細血管 / ⑥=ブドウ糖 / ⑦=アミノ酸 / ⑧=肝門脈 / ⑨=肝臓 / ⑩=リンパ管 / ⑪=肝門脈 / ⑫=リンパ管 / ⑬=脂肪酸 / ⑭=モノグリセリド / ⑮=リンパ管

Q2. ブドウ糖とアミノ酸は、毛細血管から何を通って肝臓に運ばれるか。

正解: イ：肝門脈　ブドウ糖とアミノ酸は毛細血管から肝門脈を通り、肝臓にたくわえられます。

Q3. 脂肪酸とモノグリセリドは、リンパ管からどこを通って心臓に運ばれるか。

正解: イ：胸管から大静脈　リンパ管は胸管という太い管に集まり、大静脈に入って心臓に運ばれます。

Q4. 肝門脈とはどのような血管か。

正解: ウ：消化管から出た血液が心臓に戻る前に肝臓を通る血管　このように別の器官を通る血管を「門脈」といいます。
